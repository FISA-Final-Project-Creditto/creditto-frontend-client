# Project Overview

This is a Next.js project named "creditto" that functions as a Progressive Web App (PWA). It includes user authentication features and utilizes Optical Character Recognition (OCR). The application is built with React and uses Redux Toolkit for state management and Tailwind CSS for styling.

# Building and Running

## Installation

```bash
npm install
```

## Running the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building for production

```bash
npm run build
```

## Running in production mode

```bash
npm run start
```

## Testing

The project uses Jest for testing.

```bash
npm run test
```

## Linting

The project uses ESLint for linting.

```bash
npm run lint
```

# Development Conventions

*   **Framework:** Next.js
*   **Styling:** Tailwind CSS
*   **State Management:** Redux Toolkit
*   **Testing:** Jest
*   **Linting:** ESLint
